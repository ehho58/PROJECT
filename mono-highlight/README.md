# MonoHighlight

画面をモノクロ表示にし、**指定したカラーコードに近い色だけを元の色のまま残す** Android アプリ（自分用）。
他のアプリの上に重ねて表示します。タッチ操作は下のアプリにそのまま届きます。

- 対応: **Android 14 以上**（`takeScreenshotOfWindow()` を使うため）
- 外部ライブラリなし（Android フレームワークのみ）

## 仕組み

1. ユーザー補助サービス（AccessibilityService）が画面上のウィンドウを列挙する
2. 自分のオーバーレイ**以外**のウィンドウを `takeScreenshotOfWindow()` で 1 枚ずつキャプチャする
   - 画面全体ではなくウィンドウ単位で撮るので、自分のオーバーレイが写り込んで無限ループになることがない
3. AGSL シェーダー（GPU）で「指定色との距離が許容範囲内なら元の色、それ以外は輝度だけのグレー」に変換する
4. `TYPE_ACCESSIBILITY_OVERLAY`（タッチ素通し）の全画面ビューに、元の位置に合わせて描画する
5. 設定した間隔（既定 50ms）で繰り返す

| ファイル | 役割 |
|---|---|
| `MonoHighlightService.kt` | キャプチャのループ、オーバーレイの表示と非表示 |
| `OverlayView.kt` | シェーダーでの描画（色判定のロジックはここ） |
| `MainActivity.kt` | 設定画面（カラーコード最大 4 色、許容範囲、更新間隔） |
| `ToggleTileService.kt` | クイック設定タイル |
| `Prefs.kt` | 設定の保存 |

## ビルド

**GitHub Actions を使う場合:** `mono-highlight/` を push すると
`.github/workflows/build-mono-highlight.yml` が実行されます。
Actions 画面の実行結果に Artifacts「MonoHighlight-apk」としてできた APK をダウンロードします。
手動で実行する場合は「Run workflow」を押してください。

**手元でビルドする場合:** Android Studio でこのフォルダを開くか、Android SDK を入れた環境で

```bash
cd mono-highlight
./gradlew assembleRelease   # app/build/outputs/apk/release/app-release.apk
```

## インストールと使い方

1. APK を端末に入れてインストールする（提供元不明のアプリを許可）
2. Android 13 以降でサイドロードしたアプリは、ユーザー補助を有効にする操作がブロックされることがあります。
   その場合は「設定 → アプリ → MonoHighlight → 右上の︙ → **制限付き設定を許可**」を先に行ってください
3. アプリを開き「ユーザー補助の設定を開く」から **MonoHighlight** を有効にする
4. カラーコードを入力し（例 `#FF0000`, `00A0E9`, `#F00`）、スイッチをオンにする
5. オン/オフは次の方法でも切り替えられます
   - クイック設定パネルのタイル「モノクロ強調」（パネルの編集から追加）
   - ユーザー補助ボタン

## 調整のコツ

- **許容範囲**: カラーコードの完全一致だけだと、文字のふちや画像の中の色が残りません。
  10〜25 くらいから試してください（RGB 空間でのユークリッド距離で判定しています）
- **更新間隔**: 短くすると滑らかになりますが、電池の消費が増えます。動きの少ない画面なら 100〜200ms でも十分です

## 既知の制約

- 実際の画面より数フレーム遅れて表示されます。スクロール中は少しずれて見えます
- 画面保護（`FLAG_SECURE`）されたアプリは撮影できないため、その領域はグレー化されず元の色のまま見えます
- ダイアログの背景を暗くする効果（dim）は再現されません
- 画面がオフのあいだはキャプチャを休止します
